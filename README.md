# Contributing to JajaOS
Welcome to contribute to JajaOS!

### Code Rule
- All source files must keep GPL-3.0-only header.
- Code style: simple C style, avoid heavy C++ features.
- When adding new module, create `.c` + `.h` pair.

### Submit
Fork this repo, create branch, commit and open pull request.

### Bug Report
Use GitHub issues to report bugs, include:
1. Build log
2. QEMU error message
3. Reproduce steps
